```
Here you have the output format of the card:

{
  "word": "string", // The Portuguese word
  "pronunciation": "string", // Pronunciation guide in English (e.g., "gato -> gah-too")
  "definition": "string", // Definition in Portuguese
  "example_sentence": "string", // Example sentence in Portuguese (intermediate complexity)
  "sentence_translation": "string", // English translation of the example sentence
  "notes": "string", // Usage notes, differences with Brazilian Portuguese, or other relevant information
  "audio_european": "string", // (Bonus) Base64 encoded audio of the word in European Portuguese
  "audio_brazilian": "string" // (Bonus) Base64 encoded audio of the word in Brazilian Portuguese
}

Example of OpenAI SDK with JS:

import OpenAI from "openai";
import { z } from "zod";
import { zodResponseFormat } from "openai/helpers/zod";

const openai = new OpenAI();

const ResearchPaperExtraction = z.object({
  title: z.string(),
  authors: z.array(z.string()),
  abstract: z.string(),
  keywords: z.array(z.string()),
});

const completion = await openai.beta.chat.completions.parse({
  model: "gpt-4o-2024-08-06",
  messages: [
    { role: "system", content: "You are an expert at structured data extraction. You will be given unstructured text from a research paper and should convert it into the given structure." },
    { role: "user", content: "..." },
  ],
  response_format: zodResponseFormat(ResearchPaperExtraction, "research_paper_extraction"),
});

const research_paper = completion.choices[0].message.parsed;
```
